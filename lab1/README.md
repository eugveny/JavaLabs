## Лабораторная работа №1: Базовый синтаксис и управляющие конструкции

### Задание 1: Primes.java
Программа для поиска и вывода всех простых чисел в диапазоне от 2 до 100.
* **Алгоритм проверки:** метод `isPrime(int n)` проверяет число на простоту перебором делителей в цикле от 2 до $n-1$.
* **Оптимизация:** если число делится без остатка (`n % i == 0`), метод досрочно возвращает `false`, прерывая дальнейшие проверки.

### Задание 2: Palindrome.java
Программа для проверки слов на палиндром (читаются одинаково в обоих направлениях). Файлы компиляции `.class` исключены из репозитория.
* **Переворот строки:** метод `reverseString(String s)` посимвольно обходит исходную строку с конца к началу и собирает новую строку.
* **Проверка:** метод `isPalindrome(String s)` сравнивает оригинальную строку с перевернутой с помощью метода `equals()`.
* **Аргументы командной строки:** программа обрабатывает массив строк `args`, переданных при запуске, и выводит вердикт для каждого слова.
