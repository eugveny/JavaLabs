## Лабораторная работа №3: Хэш-таблицы. Вариант 5

### Задание 1: HashTable.java & Entry.java
Собственная реализация хэш-таблицы с разрешением коллизий методом цепочек.
* **Структура:** массив связанных списков `LinkedList<Entry<K, V>>[]`.
* **Хэширование:** метод `hash(K key)` через `Math.abs(key.hashCode() % capacity)`.
* **Коллизии:** при совпадении хэша элементы добавляются в соответствующий `LinkedList`.
* **Перезапись:** если ключ уже существует, метод `put` обновляет его значение через `setValue`.

### Задание 2: Warehouse.java & Product.java (Вариант 5)
Модель электронного склада для учета товаров по штрих-кодам.
* **Хранение:** встроенный класс `HashMap<String, Product>`, где ключ — штрих-код.
* **Сущность:** класс `Product` инкапсулирует имя, цену и количество товара, переопределен метод `toString()`.
* **Операции:** методы `addProduct` и `getProduct` для быстрого добавления и поиска за константное время $O(1)$.
