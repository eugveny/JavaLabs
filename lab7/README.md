## Лабораторная работа №7: Многопоточное программирование

### Задание 1: ArraySumCalculator.java (Вариант 2)
Многопоточное вычисление суммы элементов массива.
* **Параллелизм:** использование `ExecutorService` с фиксированным пулом из 4 потоков.
* **Задачи:** класс `SumTask` реализует интерфейс `Callable<Integer>` для подсчёта суммы на конкретном отрезке массива.
* **Результаты:** массив объектов `Future<Integer>` выступает в роли "квитанций" для последующего сбора данных через метод `get()`.

### Задание 2: MatrixMaxFinder.java
Поиск максимального элемента в матрице (двумерном массиве).
* **Деление данных:** матрица разбивается построчно между 3 рабочими потоками через класс `MaxTask`.
* **Сравнение:** каждый поток находит локальный максимум на своем пуле строк, после чего в `main` вычисляется глобальный максимум.

### Задание 3: WarehouseTransfer.java (Вариант 2)
Моделирование работы склада с синхронизацией ресурсов.
* **Общий ресурс:** класс `Warehouse` с очередью товаров `Queue<Product>` и ограничением по весу для отправки машины (`MAX_WEIGHT = 150`).
* **Синхронизация:** метод `takeProduct()` помечен как `synchronized` для предотвращения состояния гонки (race condition) при одновременном обращении грузчиков.
* **Потоки:** грузчики (`LoaderRealization`) имплементируют `Runnable` и симулируют задержку работы через `Thread.sleep(500)`. Выполнение контролируется пулом потоков.
