## Лабораторная работа №8: Java Reflection API, Аннотации и Stream API
Многопоточный конвейер обработки данных с динамическим подключением модулей через рефлексию.

### Структура проекта и компоненты
* **`DataProcessor.class` (Кастомная аннотация):** маркерная аннотация с `@Retention(RetentionPolicy.RUNTIME)` для поиска целевых методов во время выполнения программы.
* **Классы-обработчики (`FilterProcessor`, `TransformProcessor`, `SortProcessor`)** содержат методы, помеченные `@DataProcessor`, которые трансформируют списки с использованием **Stream API**:
    * **`filter`** отсеивает числа меньше или равные 50 (`filter(n -> n > 50)`).
    * **`transform`** умножает каждое число на 2 (`map(n -> n * 2)`).
    * **`sort`** сортирует поток чисел по возрастанию (`sorted()`).
* **`DataManager.java` (Ядро системы)** управляет жизненным циклом данных:
    * **Ввод-вывод:** построчно читает `input.txt` через `BufferedReader` и записывает результат в `output.txt` через `BufferedWriter`.
    * **Reflection API:** метод `processData()` сканирует зарегистрированные объекты-процессоры, находит методы с аннотацией `@DataProcessor` через `getDeclaredMethods()` и вызывает их через `method.invoke()`.
    * **Многопоточность:** вызов каждого обработчика заворачивается в лямбда-выражение и отправляется на выполнение в пул потоков `ExecutorService.submit()`, синхронизируя результат через блокирующий метод `future.get()`.
